# iOS 视觉调整 · 2026-10-25

主页面统一使用系统导航和语义颜色，作品内容优先，粉色作为操作与选择状态的点缀。

- **发现**：本季精选大封面、今日放送、继续观看、本季新番、每组三部的横向排行榜；登录提示移至内容之后。
- **放送**：独立日期选择、当日作品数量、带封面与评分的分组列表。
- **搜索**：固定显示的系统搜索栏、条目/角色/人物分段选择、灵感列表。
- **收藏与我的**：统一标题、分组、空状态与登录操作。
- **详情**：封面延伸到顶部安全区域，标签取消不可交互按钮造成的灰化，正文采用系统字号。
- **底部导航**：继续使用自绘玻璃控件，增加选择动画，并尊重减少动态效果与降低透明度设置。隐藏系统 Tab Bar；移除分页样式以恢复原生导航标题的布局。
