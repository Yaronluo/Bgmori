# 每日放送 · 周历与列表调整

2026-10-26，重做「每日放送」页面的周选择器和列表排版，iPhone 与 Mac 共用一套信息结构。

## 设计

- **周选择器**：周几 + 当日作品数 + 日期；跨月显示 `11/1`；今天用品牌粉日期和圆点标记。选中态沿用中性底色和字重区分，玻璃仍只出现在这一组浮动控件上。
- **页头**：`星期一` + `今天` 徽章 + `10月26日 · 13 部作品`；浏览其它星期时右侧出现 `回到今天`。
- **列表**：封面 64×88；标题按平台使用 15 / 17 pt；副标题显示「10月5日开播」，已收藏条目显示状态。评分使用金色星标和胶囊，未评分显示「暂无」。在看条目额外显示 `在看` 徽章、已看话数和细进度条。
- **布局**：内容最大 760 pt 并居中，Mac 宽窗口不再把单行拉到整页宽；Mac 使用 `underPageBackgroundColor` 分组底色衬出白色列表卡片，窄窗口自动收窄。
- **状态**：加载骨架、空状态（`只看在看` 时提供「显示全部」）、加载失败与重试。
- 列表卡片只使用内容表面和细描边，不额外叠玻璃。

## 验证

- iPhone 17 / iOS 27.0 模拟器 Debug 构建通过，浅色、深色截图。
- 当前 Mac / arm64 Debug 构建通过，约 1261×820 窗口浅色、深色截图。
- 使用真实 `/calendar` 数据渲染，游客模式检查；封面、评分、开播日期均正常。
- 选中其它星期、`回到今天`、`只看在看` 空状态在实现路径中覆盖，未做自动化点击回放。
