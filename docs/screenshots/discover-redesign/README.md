# 发现页改版 · 2026-10-26

发现页从「本季精选 + 若干书架 + 社区入口」改为一条完整的内容动线：

1. **最近热播**：近 90 天人气动画的主视觉轮播。支持左右按钮、页码点和横向滑动，一屏只展示一部，保留封面、评分、在看人数、简介与标签。
2. **正在看**：登录后显示在看收藏，按更新时间排序；封面带播放角标，标题下显示已看进度。
3. **今日放送**：按「正在看优先、评分其次」排序，保留每日放送的完整入口。
4. **本季新番**：按本季排名筛选，板块直接进入对应分类榜单。
5. **口碑佳作**：Bangumi 动画排行榜，封面带排名与评分角标，可进入完整榜单。
6. **剧场版精选**：补充电影向内容，避免发现页只看电视动画。
7. 社区入口已从发现页移除；社区页面本身仍保留在「我的」中。

视觉上统一了板块标题层级、标题到书架的间距、书架间距、封面圆角与角标样式。Mac 首屏内容区不再重复显示「发现」标题，顶部只保留日期和每日放送 / 浏览分类两个快捷入口。
