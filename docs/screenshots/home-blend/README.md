# 首页边缘渐变与循环滑动 · 2026-10-26

最近热播移除了整块圆角卡片、边框和底板，使用当前封面的模糊色彩作为背景，并在四周逐渐淡出到页面背景。完整封面也使用轻微边缘渐变。iPhone 与 Mac 均保留日期、简介、评分、在看人数及集数；Mac 题材标签仍保留。

轮播只保留可点击的小圆点，移除数字页码和左右箭头。手动滑动与每 6 秒自动轮播均支持首尾循环：最后一项继续左滑进入第一项，第一项继续右滑进入最后一项。通过首尾衔接页，跨过边界后仍能继续滑动。手动操作后重新计时；滚动中、应用不活跃或开启减少动态效果 / 旁白时暂停自动切换。
