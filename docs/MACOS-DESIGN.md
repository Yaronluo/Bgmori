# macOS 页面调整 · 2026-10-25

为桌面窗口单独安排内容宽度、导航与操作层级，保留 iPhone 的布局。

- 侧栏：原生 List 选择状态；账户和设置放在底部。
- 发现：完整竖版封面搭配简介，限制内容宽度；章节入口使用轻量文字按钮。
- 搜索：页内输入框、紧凑的范围切换、有限宽度的搜索记录和灵感列表。
- 我的：账户卡片，以及并排的资料库、社区入口。
- 条目：封面与标题并排，收藏、进度操作集中于标题旁；移除 Mac 底部重复操作条。内容宽度达到 860 pt 时，简介与信息并排；较窄窗口改为上下排列。
